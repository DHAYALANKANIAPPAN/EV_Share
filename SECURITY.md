# Security

Please **do not open a public issue** for a security problem. Use GitHub's private reporting: **Security tab > Report a vulnerability** on this repository. We aim to reply within a few days.

EV Share handles identity documents and payments. If you run your own copy: use HTTPS, keep `.env` and the document encryption key private, use a strong reviewer password, choose an unguessable `EVSHARE_STAFF_PATH`, and keep the app updated.
